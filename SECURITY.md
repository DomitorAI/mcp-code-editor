# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for a security problem. Report it privately:
[Security → Report a vulnerability](https://github.com/DomitorAI/mcp-code-editor/security/advisories/new) —
only the maintainers can see the report.

Include what you can: the component (application, MCP server, tunnel, install scripts), the version, the steps to
reproduce and what an attacker could do. Never include real tokens, keys or personal data.

You will get an answer in the report; once a fix is released, the advisory is published with credit to you (if you wish).

## Supported versions

Only the latest release is supported: fixes come as a new version.
